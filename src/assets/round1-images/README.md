## Image Requirements

- Format: `.jpg` (or `.png` if preferred)
- Content: Dental instruments or dental procedures
- Recommended size: 800×600 or similar reasonable resolution
- File size: Keep under 500KB per image for optimal performance

## Usage

These images will be automatically loaded by the Custom Game when Round 1 is set to "Image Mode".

The filenames are **exact and required** - the application expects these specific names.
